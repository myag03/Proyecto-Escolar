PLANTILLA WEB - INSTITUTO AMÉRICA

Carpetas:
  index.html     -> la página (textos y estructura)
  css/estilos.css -> colores y diseño (los colores están al inicio, en :root)
  js/script.js    -> menú móvil, barra de progreso, animaciones
  img/            -> imágenes. Para usar una foto: guárdala aquí y cambia
                     el src en index.html, por ejemplo src="img/mi-foto.jpg"

Para empezar: abre index.html con doble clic y edítalo con VS Code o el Bloc de notas.
Para agregar una sección: copia un bloque <section id="..."> y agrega su enlace en el menú.
